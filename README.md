# TypeScript Task Manager

A simple CLI-based Task Manager built with TypeScript.

## Features

* Add tasks
* List tasks
* Edit tasks
* Complete tasks
* Reopen tasks
* Delete tasks
* Search and filter tasks
* Input validation
* Unit testing with Vitest

## Technologies

* TypeScript
* Node.js
* Vitest
* readline-sync

## Installation

```bash
npm install
```

## Run

```bash
npx tsx src/index.ts
```

## Run Tests

```bash
npm test
```

## Project Structure

```text
src/
├── services/
│   ├── taskService.ts
│   └── taskService.test.ts
├── types/
│   └── task.ts
└── index.ts
```

## Purpose

This project was built to practice TypeScript fundamentals, project organization, testing, and Git/GitHub workflows.
